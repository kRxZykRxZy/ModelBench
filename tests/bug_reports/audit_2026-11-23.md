# ModelBench Bug Audit — 2026-11-23

Subagent: agent-8 (bug finder). Scope: C++ (app/**), QML (app/ui/**), CMake build integration. No builds were run; findings are by inspection.

## Build-breaking

- **BUG-202** — Root `CMakeLists.txt` does not list the new `app/agent/*.cpp/.h` (AgentPlanner, AgentOrchestrator) or `app/tools/*.cpp/.h` (ToolRegistry, ToolApproval, FileEditHistory, FileSystemTools, TerminalTool, GitTools) sources, so the executable cannot link the agent/tool stack. `app/models/ModelDownloads.cpp` is listed twice. `tests/CMakeLists.txt` does not `add_subdirectory(tools)` or `add_subdirectory(agent)`, so the tool/agent test fragments are never compiled. (owner: agent-1)
- **BUG-203** — `app/ui/ModelsView.qml` declares `id: localList` twice (two `ListView`s in the same component scope). Duplicate ids are a QML load error. (owner: agent-3)

## Runtime QML

- **BUG-204** — Child views reference an undefined `window` id for navigation: `SettingsView.qml`, `OnboardingWizard.qml`, `HomeView.qml`, `CreditsView.qml`, and `ChatView.qml` use `window.currentView = ...`. `window` is only the id of the `ApplicationWindow` in `Main.qml` and is not in child-component scope, so these assignments throw a runtime ReferenceError and navigation silently fails. (owner: agent-3)
- **BUG-205** — `HeaderBar.qml` toggles theme with `Theme.mode = ...`, but `Theme` (app/core/Theme.h) exposes only a constant `dark` property and no `mode` property/setter; the toggle is dead and emits a binding error. (owner: agent-3)
- **BUG-206** — `HomeView.qml` quick action "Model Fit Calculator" sets `currentView = "calculator"`, but `Main.qml` has no calculator view and `viewIndex()` has no `"calculator"` case (falls through to 0/home), so the button does nothing. (owner: agent-3)

## Security / resource handling

- **BUG-207** — `SecretStorage.cpp`: `store`/`load`/`remove` build file paths directly from unsanitized `service`/`account` strings, allowing path traversal / invalid filenames; `createSecretStorage()` returns a raw pointer with no owner (leak). (owner: agent-11)
- **BUG-208** — `MCPServerManager::connectServer()` allocates a new `MCPClient` per connect and retains it; `removeServer()` drops the pointer from `m_clients` without `deleteLater`, and `disconnectServer()` never frees the client, leaking clients on reconnect/remove. (owner: agent-4)

## Notes

- `credits` context property is intentionally `nullptr` and QML guards with `credits && credits.balance`, so no crash there.
- `Theme` is fully constant (light mode not implemented) — tracked as IDEA-111; only the toggle write (BUG-205) is a confirmed defect.
- No duplicate bugs from agent-11/security reports were re-filed; only items not already covered by todo.md [BUG-201] are listed here.
